---

## About

Noore Jewels is a premium online fine jewellery brand specialising in **IGI Certified Lab Grown Diamond** engagement rings, solitaire rings, stackable rings, and fine jewellery. All pieces are set in **9KT, 14KT, and 18KT solid gold** or **925 Silver**.

Every diamond is **IGI certified** and every piece comes with a **lifetime warranty**.

---

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Styling:** Vanilla CSS (globals.css)
- **Database:** Google Sheets (via Sheets API)
- **Auth:** OTP-based phone authentication (Firebase / custom)
- **Payments:** Razorpay
- **Deployment:** Vercel
- **Media:** Google Drive (product images)

---

## Key Features

- 🛍️ Full e-commerce with cart, checkout, and order tracking
- 💎 Dynamic pricing based on gold purity (9K / 14K / 18K / 925 Silver)
- 💬 WhatsApp integration for customer support
- 📧 Exit intent popup with WhatsApp coupon capture
- 📦 Order management via Google Sheets
- ⭐ Customer review system
- 📊 Admin trend finder tool (weekly email report)
- 🔍 Full SEO with JSON-LD structured data
